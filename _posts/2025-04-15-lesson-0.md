## Objectives
- Understand what git and GitHub are.
- Clone, edit, and push code to a braanch. 
- Set up local Python environment
- Create a basic Python script

## Instructions
- Create your GitHub account - remember your email address. If you do not have your own
email address, quickly make one now. [https://github.com](https://github.com)
- Open command prompt or a terminal (on windows, hit the windows key and search for
“CMD”).
- Setup your local git config, using the email of your GitHub account login. [https://git-scm.com/book/en/v2/Customizing-Git-Git-Configuration](https://git-scm.com/book/en/v2/Customizing-Git-Git-Configuration)
  - `git config --global user.name "<name you want to show on GitHub>"`
  - `git config --global user.email "<your GitHub email address>"`
- Clone the `advanced_python` repository.
  - `git clone https://github.com/cork-airport-dojo/advanced_python`
- Change directory to the root of the repository - `cd advanced_python`
- Create a new branch – `git checkout -b <your_github_username>`
- Open the code in Visual Studio Code - `code advanced_python`
- Create a new file `main.py`
  ```python
  def main():
      print("Hello world")

  if __name__ == "__main__":
      main()
  ```
- Write a bit of code and run it with `python main.py` in the terminal - you're not allowed run the code from the IDE anymore.
- Stage your changes for commit - `git add main.py`
- Commit your changes `git commit -m "Your commit message"`
- Push your branch `git push origin <your branch name>`
- See your changes on GitHub [https://github.com/cork-airport-dojo/advanced_python](https://github.com/cork-airport-dojo/advanced_python)
  - Change the branch to yours, and see your changes.
