## Objectives
- Create object-oriented code to simulate a book-loaning library.
- Learn how classes work in python
  - Learn about inheritance

## Instructions

- Create a new folder/directory called `book_loaning`.
- Create 5 new files in this directory.
  - book.py
  - author.py
  - member.py
  - user.py
  - library.py

You will define 3 classes - `Book`, `Author`, and `Member`.

```py
class B(A):
  """Class B **inherits** from  A"""

  # these are properties
  # essentially variables that will be in each object
  property1
  property2

  def __init__(self, p1, p2):
    """
      This method is the **constructor**. 
      It is basically code used to create a class instance.
    """
    # note that self is basically the instance that we are creating.
    self.property1 = p1
    self.property2 = p2

  def set_property1(self, p1):
    """Here is another method, to update a property"""
    self.property1 = p1

# e.g. creating an instance of the class
s = Something()
# set a value
s.property1 = "Something"

# use a value 
print(s.property2)
```

To have a class inherit properties and methods from a parent class

The following properties will be needed:
- `Book`
  - `title`, `published_date`, `author`, and `loaned_to`.
- `User`
  - `first`, `last`
- `Member`
  - `borrowed_books`
- `Library`
  - `users`, `books`

Apart from `loaned_to` and `borrowed_books`, you will need to set these values in the `__init__` constructor.

You will define methods in `Library` class to manage borrowing and returning of books.
These methods will have to manage updating data of both the member and the book.
